# MERFISH 留出切片验证：表达方差收缩与稀有细胞恢复机制分析及改进方案

记录日期：2026-10-15。修订日期：2026-10-15。

本文件依据[原始问题记录](../ccfa-workfiles/ideas/merfish-holdout/research-problems.md)、[逻辑与实现审查报告](../ccfa-review-reports/merfish-mechanism-plan-review.md)、现有实现和已完成的留出结果，讨论两个研究方向：表达偏低、总表达方差收缩与基因依赖偏离；稀有类型的缺失及其表达恢复不稳定。

**目前能够确认的是生成结果中的统计偏差、原算法逐基因分别抽样的条件独立性质，以及部分稀有类型的候选供体数量很少。具体误差的因果贡献和改进效果仍需受控验证。**

本文保留原有五个候选模块，并修正其适用条件和实验安排。文中的原始运行数据、对既有输出的离线复算、数学推导和未执行的改进实验分别标明来源。审查报告针对修订前的原稿，其行号不对应本次修订后的文件。

## 2. 表达偏差的机制分析：可证明性质与待验证归因

### 2.1 原实现实际执行什么

`SpatialZ.py` 的 `synthesize_gene_expression` 按以下顺序执行：

1. 合并两张输入，共 11,414 个参考细胞。
2. 在合并坐标上建立全局 `cKDTree`。
3. 对每个生成细胞，统计合并输入中的同类型细胞数 `N_c`。
4. 在全局树查询 `min(k_sam,N_c)` 个近邻，再筛出其中同类型的细胞。
5. 用候选供体与生成细胞的 MENDER **余弦相似度**计算权重。
6. 每个基因分别按同一组权重抽取供体，并复制该供体对应基因的表达值。

原权重为：

```text
score(i,m) = Beta × cosine(e_m, e_i)
w(i,m) = exp(score(i,m)) / sum_m exp(score(i,m))
```

空间距离决定候选池，MENDER 决定候选池内的抽样权重。因此，原实现已经使用 MENDER，也不使用 `exp(-Beta × 空间距离)`。余弦相似度在 [-1,1] 内，本次 `Beta=1` 时指数项在 [exp(-1),exp(1)] 内，不会因空间距离较大而下溢。

### 2.2 逐基因独立抽样的条件性质

用 `H_i` 表示生成细胞 i 的完整条件信息，包括类型、供体索引、供体表达向量和权重。仅列出权重数值不足以确定条件分布。

设在该供体池中整细胞加权抽样的均值为 `mu_i`、协方差为 `C_i`。在固定 `H_i` 时：

```text
逐基因分别抽样：
    E[X_gene | H_i] = mu_i
    Cov(X_gene | H_i) = diag(C_i)

每细胞抽一次完整供体向量：
    E[X_cell | H_i] = mu_i
    Cov(X_cell | H_i) = C_i
```

二者各基因的条件边际分布相同，但不同基因是否共享供体决定其条件依赖。对总表达 `T=sum_j X_j`：

```text
Var(T_cell | H_i) - Var(T_gene | H_i)
    = 2 × sum_{j<k} C_i[j,k]
```

若交叉协方差之和为正，逐基因抽样的条件总表达方差较小；若为负，关系可能相反。只有一个有效供体时 `C_i=0`，两种抽样都输出同一个确定向量，无法靠改变抽样单元增加多样性。

总体协方差还满足：

```text
Cov(X) = E_H[Cov(X | H)] + Cov_H(E[X | H])
```

以上是给定参考数据和生成条件下的抽样性质。真实中间切片与供体池的条件分布并不天然相同；跨位置的局部均值分布、类型组成及测量差异也会影响总体统计量。因此，这些公式不能直接证明本次 19.84% 标准差偏差、相关性 0.9401 或具体分位数全部由独立抽样造成。

对有限且不等分布的 155 个基因，不能仅援引中心极限定理就推出本次尾部和标准差数值。应先通过固定候选与权重的单因素对照，测量改变抽样单元的实际影响。

输入总表达均值为 240.97、242.98，等权平均为 241.98；合成为 243.02，真实中间为 256.97。合成接近输入水平，真实中间高于两端。这一统计现象可能涉及生物变化、细胞组成、测量或预处理差异，尚不能直接称为已确定的真实生物峰值。

```text
生成均值 - 真实均值
= sum_r (生成区域比例 - 真实区域比例) × 真实区域均值
```

## 3. 稀有细胞恢复：类型出现、供体支持与统计不确定性

### 3.1 类型缺失需要结合输入丰度解释

原坐标优化不按细胞类型分别约束；后续近邻赋型没有全局计数配额。这意味着类型出现没有计数保证，但不证明该算法一定系统性压制稀有类型，也不能由稀有细胞数量少推导其有效 Voronoi 区域面积趋近于零。

OD Mature 3 的输入数量为 0 和 2，按输入比例等权平均得到的数量参照为：

```text
lambda = 5707 × (0.5 × 0/5488 + 0.5 × 2/5926)
       = 0.963044
```

参照值不足 1。输出为 0 是本次类型缺失事实，但是否属于算法性漏生成，应结合其他留出位置、重复生成和丰度先验检验。一旦某类型未被赋给任何生成细胞，表达采样阶段也无法增加该类型的细胞。

### 3.2 合并 KD-tree 中的候选供体确实较少

按原检索逻辑，在已有合成坐标上复算：

| 类型 | 合并输入同类型数 | 全局查询上限 | 每个合成细胞的有效同类供体数 |
| --- | ---: | ---: | --- |
| OD Immature 2 | 14 | 14 | 1、1、3、3、1、1、3、1 |
| OD Mature 4 | 18 | 18 | 2、1、1、1、1、1 |
| OD Mature 3 | 2 | 2 | 没有该类型合成细胞，不存在实际表达查询 |

这说明全局截断后筛类会限制候选集合，但不能写成所有稀有类别必然只有 0–1 个供体。把空间近邻当成全局独立随机抽样，再计算 `(1-p)^k`，缺少相应模型；本文件不保留原稿的 99.66%/99.58% 供体丢失概率。

候选数量少、供体与目标的真实差异、小样本均值估计以及生成抽样方式，都可能影响稀有类型相关性。候选集限制是可检验的因素，不是目前已经唯一确定的原因。

### 3.3 候选数量与有效样本量不同

对一个局部候选池，核权重有效样本量可用：

```text
ESS_i = 1 / sum_m w(i,m)^2
```

均匀权重时 ESS 等于候选数，权重集中时更小。该值衡量加权支持的集中程度，不代表供体提供了同样数量的独立生物学样本。输入同类型总数 14、18 不能直接写作局部有效样本量。

真实稀有类型只有 3–11 个细胞，类型内均值与高维相关结构的估计不稳定。按细胞重采样可提供条件于当前样本的描述性不确定性，但无法补出缺少的亚状态，也不能自动获得具有真实 95% 覆盖率的区间。


## 4. 候选改进方案：作用对象、成立条件与风险

五个模块均为待验证设计。先检验单因素，再决定是否组合；目前没有执行这些模块的正式留出生成实验。

### 4.1 模块 1A：整细胞联合采样，残差组合作为扩展

#### 首选受控版本：共享一个供体索引

固定原来的合并候选池和 MENDER 权重，令一个生成细胞的全部基因共享一次抽样得到的供体索引：

```text
m_i ~ Categorical(w_i)
X_syn[i,:] = X_reference[m_i,:]
```

它保持第 2.2 节定义的各基因条件边际分布，并保留该加权供体分布的条件协方差。由于供体表达本身非负，无需非负截断。

这个保证针对给定供体分布和抽样期望，不保证有限次生成的逐基因均值、Pearson 或真实目标协方差精确不变。它也可能复制有限供体的表达向量。若供体池本身有偏，联合采样会保留该偏差，需要与模块 2A 的候选集检验分开。

#### 扩展版本：两侧局部均值与完整残差

若以后需要分别构建两侧供体池，可定义：

```text
mu_i = (1-t) mu0_i + t mu1_i
r0_i = X0_draw - mu0_i
r1_i = X1_draw - mu1_i
```

给定两侧完整供体条件，两残差均值为零。以下性质只针对未截断变量：

| 算子 | 表达式 | 条件协方差 |
| --- | --- | --- |
| A：残差路由 | X_tilde = mu_i + (1-B) r0_i + B r1_i，B~Bernoulli(t) | (1-t) Sigma0_i + t Sigma1_i |
| B：独立残差缩放 | X_tilde = mu_i + ((1-t) r0_i + t r1_i)/sqrt((1-t)^2+t^2) | ((1-t)^2 Sigma0_i+t^2 Sigma1_i)/((1-t)^2+t^2) |

两残差应独立抽取，B 应独立于残差选择。A 与 B 在 t=0.5 时相同；两侧协方差相同时也相同；一般情形下它们不是同一个线性加权协方差目标。例如 t=0.25、Sigma0=1、Sigma1=9，A 为 3，B 为 1.8。

直接平均两侧独立完整向量的条件协方差为 `(1-t)^2 Sigma0+t^2 Sigma1`。在中点、两侧协方差相同的特定情形下，这会成为原协方差的一半。但当前原算法并不执行两侧向量直接平均，不能把该现象作为本次原始运行方差收缩的额外原因。

#### 非负性与矩保证

加残差后的 `X_tilde` 可能为负。执行 `max(X_tilde,0)` 后，截断前的矩保证不再自动成立。

例如两侧等权单基因供体池 {0,2} 与 {0,20}，中点均值为 5.5，算子 A 的未截断值为等概率的 {4.5,6.5,-4.5,15.5}。截断使均值从 5.5 变为 6.625，方差从 50.5 变为 31.796875。

因此，残差版本应另行定义非负输出机制，并报告负值率、截断前后均值及协方差差异。即使保持某个输入条件矩，也不等于恢复未知的中间切片分布。当前首选对照采用直接整细胞采样，将该扩展留待单独验证。

### 4.2 模块 1B：在已有 MENDER 权重上增加空间核

原实现已用 MENDER 余弦相似度定权。候选扩展是在同一个供体集合中额外加入空间距离惩罚：

```text
log_weight(i,m)
    = Beta × cosine(e_m,e_i) - beta_s × distance(s_i,s_m)/h_i
w(i,m) = softmax_m(log_weight(i,m))
```

保持 Beta 与原基准相同，beta_s=0 时恢复原权重分布，beta_s>0 才加入空间核。带宽 h_i 可以选为候选池中正距离的中位数，并对零距离、单供体和极小带宽定义统一规则。数值计算可先减去最大 log_weight，再取指数，避免新距离项造成下溢。

该模块检验候选距离与微环境是否足以改善局部表达。区域边界两侧的 MENDER 向量未必不同；即使向量不同，也不保证核权重能准确隔离生物亚状态。因此，不能声称自动阻断跨区域供体或必然抬高 Pak3、Ar、Prlr 的均值。

应记录跨区域候选数量、距离、最终权重及 ESS，并检查减少空间跨度是否同时减少了供体支持、加重稀有类复制。带宽与 beta_s 的选择属于开发过程，不由目标切片误差反推后仍作为未见测试报告。

### 4.3 模块 2A：合并输入内的类内 KD-tree 检索

首个检索对照保留合并参考数据，不改变来源混合比例或增加距离核，只将“全局截断后筛类”改为：

```text
I_c = 合并输入中属于类型 c 的细胞索引
Tree_c = cKDTree(reference_coords[I_c])
在 Tree_c 内查询 min(k_sam,len(I_c)) 个供体
```

本次 OD Immature 2 和 OD Mature 4 分别只有 14 和 18 个参考细胞，因此该查询会返回全部同类型细胞。这里的完整返回只针对参考候选，不是生物学恢复率，也不保证远处供体适合该生成位置。定权仍使用原 MENDER 余弦规则，以隔离检索顺序的影响。

该模块只改变已被赋型细胞的表达供体，不能让原来没有生成的 OD Mature 3 类型自行出现。类型缺失需要另行检验赋型机制，例如模块 2B，不能将检索改善与类型覆盖率改善混为一项。

该设计自然支持只有一侧存在某类型的情况，因为参考池已合并。若以后另行采用分侧供体池和来源权重，需要明确缺失侧的表达回退，并单独作为因素检验。两侧均无供体时，不应静默输出零向量或假定可以恢复未见类型。

将类内检索与自适应带宽同时开启，会混合候选集和权重两个变化，不能作为检索顺序的单因素证据。

### 4.4 模块 2B：输入先验下的离散配额指派与计数参照

#### 输入计数先验

定义：

```text
p_input(c,t) = (1-t) N0_c/N0 + t N1_c/N1
lambda_c = N_syn × p_input(c,t)
```

它假设中间类型比例可由两端线性插值，属于待验证先验。通过最大余数法将期望计数化整为总和等于 N_syn 的配额 q，可获得明确的输出计数约束，但不一定为每个极低丰度类型分配至少一个细胞。

#### 有限点到有限类别的配额指派

构造生成点到各类别供体的距离代价 D，并求解：

```text
min sum_i,c Pi[i,c] D[i,c]
sum_c Pi[i,c] = 1
sum_i Pi[i,c] = q_c
Pi[i,c] >= 0
```

这是离散运输/有配额指派。行供给和列需求均为整数时，运输问题存在整数最优解；使用网络单纯形求解后，仍需检查成功状态、边际满足与硬赋型结果的计数。若改用软运输后直接 argmax，应额外检查是否破坏配额。

全局最优指派考虑类别之间的竞争，不保证给某一类别单独选择其距离最近的点。代价的近邻数、距离尺度以及单侧缺失回退规则都需要固定后比较。

#### Poisson 只作为模型假设下的数量参照

固定总生成数且假定细胞类型独立同分布时，类型计数更自然地对应多项分布，各类别计数相关。对稀有类别，可在相应条件下用 Poisson(lambda_c) 作近似：

```text
P(K_c >= 1 | lambda_c) = 1-exp(-lambda_c)
参照区间 = [Poisson.ppf(0.025,lambda_c), Poisson.ppf(0.975,lambda_c)]
```

该计算把输入比例估计值视为已知，没有包含其估计误差、空间依赖和中间丰度变化的不确定性。表中的概率和区间不是经校准的真实生物存在概率；生成算法如果固定配额，也不按该 Poisson 分布随机产生计数。

| 类型 | lambda_c | 假设模型存在概率 | Poisson 参照区间 | 本次输入先验的最大余数配额 | 原合成 / 真实数量 |
| --- | ---: | ---: | --- | ---: | --- |
| OD Immature 2 | 7.087184 | 99.9164% | [2,13] | 7 | 8 / 5 |
| OD Mature 3 | 0.963044 | 61.8271% | [0,3] | 1 | 0 / 3 |
| OD Mature 4 | 8.936412 | 99.9868% | [4,15] | 9 | 6 / 11 |

真实计数落在这三个参照区间内，不足以证明区间有效。概率预测应在未参与选型的多个样本上检查覆盖、区间宽度与存在概率校准。按该假设模型，OD Mature 3 输出 0 的概率约为 38.17%，单次零输出不是系统性漏检的证明。

#### 配额与生物恢复的区别

配额 q_c=1 可以保证输出一个该类型标签，但该细胞的位置、表达和身份仍需要评价。更改类型后要重新计算依赖类型组成的 MENDER 特征，再合成表达；这些变化应在实验归因中注明。

Region 配额若只修改标签，固定坐标和表达矩阵时不会改变任何基因均值。本次 MPN 输入等权比例约为 19.60%，真实为 24.55%，因此满足输入区域配额也不保证真实区域比例改善。若未来希望区域约束影响表达，需明确区域如何进入供体选择或生成模型，并作为另一个机制检验。

### 4.5 模块 2C：局部父谱系均值收缩，作为单独候选

在预先定义的父谱系 P(c) 内，计算与子类相同空间位置相关的局部父类均值，并考虑：

```text
mu_shrink(i,c) = (1-eta_i) mu_child(i,c) + eta_i mu_parent(i,P(c))
eta_i = tau/(ESS_i+tau)
```

该式是启发式谱系均值收缩，tau 与 ESS 的使用规则需要明确。它不是已经建立风险保证的 James–Stein 估计，也不能仅凭公式名称认定为已推导的经验贝叶斯模型。若采用全切片父谱系均值，应明确写成全局先验，并单独验证其与局部均值的差别。

收缩可能降低均值估计噪声，也可能偏向大样本父类、稀释稀有子类特征。估计器方差下降与生成细胞生物异质性保持是两个目标；收缩局部均值还会改变总体协方差中的均值项，不能保证 Pearson 提高、总表达方差保持或 bootstrap 区间缩窄。

若单侧缺少子类，须规定是否允许借用该侧父类信息，避免将其悄然混入已声明的单侧回退。候选策略是先在局部均值评价中检验收缩收益，再决定非负、保留子类特征的生成方式。本次不将它与残差截断打包作为默认算法。


## 5. 最小对照代码与集成顺序

以下为可离线检查的数组级示例，用于构造候选集合、固定 MENDER 权重及比较采样单元。它不包含完整的五模块实现，不直接替换原 AnnData 接口，不宣称已经完成服务器兼容性与效果验证。依赖使用现有 NumPy、SciPy、scikit-learn。

```python
import numpy as np
from scipy.spatial import cKDTree
from sklearn.metrics.pairwise import cosine_similarity


def build_candidates(reference_coords, reference_types,
                     query_coords, query_types,
                     k_sam=50, mode="global_filter"):
    """Return global reference indices; change only the lookup rule."""
    ref_xy = np.asarray(reference_coords)
    ref_types = np.asarray(reference_types)
    qry_xy = np.asarray(query_coords)
    qry_types = np.asarray(query_types)
    if mode not in {"global_filter", "within_type"}:
        raise ValueError("Unknown lookup mode")
    if not isinstance(k_sam, (int, np.integer)) or k_sam < 1:
        raise ValueError("k_sam must be positive")
    if ref_xy.shape != (len(ref_types), 2):
        raise ValueError("Invalid reference coordinates/types")
    if qry_xy.shape != (len(qry_types), 2):
        raise ValueError("Invalid query coordinates/types")
    if not np.isfinite(ref_xy).all() or not np.isfinite(qry_xy).all():
        raise ValueError("Coordinates must be finite")
    if not len(ref_types):
        raise ValueError("Empty reference data")

    global_tree = cKDTree(ref_xy)
    groups = {}
    for c in np.unique(qry_types):
        ids = np.flatnonzero(ref_types == c)
        tree = cKDTree(ref_xy[ids]) if len(ids) else None
        groups[c] = (ids, tree)

    candidates = []
    for xy, c in zip(qry_xy, qry_types):
        ids, tree = groups[c]
        if not len(ids):
            candidates.append(np.empty(0, dtype=int))
            continue
        k = min(k_sam, len(ids))
        if mode == "global_filter":
            _, found = global_tree.query(xy, k=k)
            found = np.atleast_1d(found).astype(int)
            found = found[ref_types[found] == c]
        else:
            _, local = tree.query(xy, k=k)
            found = ids[np.atleast_1d(local).astype(int)]
        candidates.append(found)
    return candidates


def mender_weights(reference_features, query_features,
                   candidates, Beta=1.0):
    """Original cosine rule; calculate once and share across sampling modes."""
    ref = np.asarray(reference_features)
    qry = np.asarray(query_features)
    if ref.ndim != 2 or qry.ndim != 2 or ref.shape[1] != qry.shape[1]:
        raise ValueError("MENDER feature dimensions differ")
    if len(candidates) != len(qry) or not np.isfinite(Beta):
        raise ValueError("Invalid query count or Beta")
    if not np.isfinite(ref).all() or not np.isfinite(qry).all():
        raise ValueError("MENDER features must be finite")

    weights = []
    for i, ids in enumerate(candidates):
        if not len(ids):
            raise ValueError(f"Query {i} has no same-type donor")
        scores = Beta * cosine_similarity(ref[ids], qry[i:i+1]).ravel()
        scores -= scores.max()
        w = np.exp(scores)
        weights.append(w / w.sum())
    return weights


def sample_expression(reference_X, candidates, weights,
                      sampling_unit="gene", seed=42):
    """Dense nonnegative expression; only donor-sharing differs."""
    X = np.asarray(reference_X)
    if sampling_unit not in {"gene", "cell"}:
        raise ValueError("Unknown sampling unit")
    if X.ndim != 2 or not np.isfinite(X).all() or np.any(X < 0):
        raise ValueError("Expected finite nonnegative dense expression")
    if len(candidates) != len(weights):
        raise ValueError("Candidate/weight counts differ")
    rng = np.random.default_rng(seed)
    G = X.shape[1]
    out = np.empty((len(candidates), G), dtype=X.dtype)
    for i, (ids, w) in enumerate(zip(candidates, weights)):
        ids = np.asarray(ids, dtype=int)
        w = np.asarray(w, dtype=float)
        if not len(ids) or w.shape != ids.shape:
            raise ValueError(f"Invalid donor pool for query {i}")
        if np.any(ids < 0) or np.any(ids >= len(X)):
            raise ValueError("Donor index out of bounds")
        if not np.isfinite(w).all() or np.any(w < 0) or w.sum() <= 0:
            raise ValueError("Invalid donor weights")
        w = w / w.sum()
        if sampling_unit == "cell":
            out[i] = X[rng.choice(ids, p=w)]
        else:
            selected = rng.choice(ids, size=G, p=w)
            out[i] = X[selected, np.arange(G)]
    return out


def _check_sampling():
    # Engineering check: donor support and shared-vector sampling.
    xy = np.array([[0., 0.], [1., 0.], [2., 0.], [3., 0.]])
    types = np.array(["A", "B", "A", "B"])
    qxy = np.array([[.1, 0.], [2.9, 0.]])
    qtypes = np.array(["A", "B"])
    global_pool = build_candidates(xy, types, qxy, qtypes, k_sam=2)
    class_pool = build_candidates(xy, types, qxy, qtypes,
                                  k_sam=2, mode="within_type")
    assert [len(ids) for ids in global_pool] == [1, 1]
    assert [set(ids) for ids in class_pool] == [{0, 2}, {1, 3}]
    X = np.array([[0., 2.], [4., 0.], [2., 0.], [0., 4.]])
    pools = [class_pool[0]] * 64
    features = np.array([[1., 0.], [0., 1.], [1., 0.], [0., 1.]])
    weights = mender_weights(features, np.tile([1., 0.], (64, 1)), pools)
    cell = sample_expression(X, pools, weights, "cell", seed=42)
    gene = sample_expression(X, pools, weights, "gene", seed=42)
    assert np.all(cell.sum(axis=1) == 2.)
    assert np.any(gene.sum(axis=1) != 2.)
    assert np.all(cell >= 0) and np.all(gene >= 0)


if __name__ == "__main__":
    _check_sampling()
```

示例末尾的自检只检验检索规则和供体索引共享。在该例的负相关表达谱中，整细胞采样的总表达为常量，而逐基因抽样产生不同总量，也说明整细胞抽样并非总会增加方差。它不是 MERFISH 性能实验。

### 5.1 怎样保持比较可解释

- 两个采样组使用同一个 `global_filter` 候选列表、同一个权重列表和同一套坐标及类型。只改变 `sampling_unit`。
- 重抽逐基因组作为本次对照基准。示例使用 `default_rng`，原流程使用 NumPy 全局随机状态，两者不保证种子相同就逐元素重现已归档输出；分布规则与输入条件一致，而归档输出保留作历史参照。
- 检索对照使用 `within_type`，其后仍使用原余弦权重，暂不启用距离核。它改变了候选集合，应与采样单元的变化分别比较。
- 示例对空候选明确报错。正式对照必须统一并记录空候选的处理规则，不能让一组填零、另一组自动回退后仍称只改变抽样方式。
- 当类型计数被配额模块改变时，应在新标签上重算 MENDER。保持标签不变的对照可共享一次计算的特征。

### 5.2 AnnData 与 MENDER 的衔接

读取两张输入，确认基因顺序和注释一致，固定合成坐标与类型后，使用现有 `perform_microenv_measure` 配置得到两张输入与合成的特征。参考坐标、表达、类型及 MENDER 行必须以相同顺序合并；权重算好后，在采样对照中共享。

原输入 h5ad 未保存此次生成时内存中的 MENDER 特征。因此现有离线候选数可以复算，原权重和局部加权协方差则需要按原配置重建特征后核对。不能用输入类型总数代替这些未保存的权重信息。

数组输出写回 AnnData 时，应保留基因顺序、生成细胞标识、坐标和注释，检查有限值、非负值与全零细胞，并为每次正式运行保存参数和评价记录。对于稀疏表达矩阵，应由适配层明确处理，不能把本示例的密集数组约定直接推广为所有输入格式。

## 6. 消融实验设计：从单因素到组合

以下实验均未执行。用于解释机制的对照先固定已有合成坐标与类型，并重建、核对所需特征。评价真实 0.09 时只在生成后计算指标；本次修改不启动这些实验。

| 对照 | 固定条件 | 唯一或明确变化的因素 | 能回答的问题 |
| --- | --- | --- | --- |
| E0：逐基因基准重抽 | 原坐标、类型、合并全局候选、余弦权重 | 重新抽样形成同一比较框架 | 原抽样规则的统计参照 |
| E1：整细胞抽样 | 与 E0 共享候选和权重 | 各基因是否共享供体索引 | 采样单元对联合结构的影响 |
| E2：类内检索 | 原坐标、类型、余弦定权、逐基因抽样 | 全局截断后筛类改为类内直接检索 | 候选集合对稀有表达的影响 |
| E3：整细胞加类内检索 | 使用 E2 候选与权重 | 在 E2 上改为整细胞抽样 | 检索与采样单元是否存在交互 |
| E4：空间核 | 使用 E3 的坐标、类型和候选 | 增加空间距离项，保持 MENDER 定义 | 权重局部性是否改善表达 |
| E5：配额赋型 | 坐标与表达采样规则固定 | 改变类型计数与位置指派，并重算 MENDER | 输入计数先验的整体影响 |
| E6：谱系均值收缩 | 先固定供体与权重，评价局部均值 | 只改变均值估计器 | 小样本借力的偏差与方差收益 |

E5 的 MENDER 重算是类型变化的必需衔接，因而该组评价的是“配额赋型及其后续依赖重算”的完整效应，不能声称仍只改变一个数组标签而其他条件完全不变。E6 在均值估计层面先验证；若进一步加入新的表达生成机制，应另列组合实验。

固定候选/权重时，E0 与 E1 的各基因条件边际和期望均值相同。有限样本的 MAE、Pearson、总表达标准差与真实切片距离仍需测量，不预告 `0.960+` 或 `66–69` 等未经实测的改善范围。

各组应记录候选数量、ESS、供体类型/来源、重复供体比例及空候选数。只有参考池不再受限却仍有偏差时，才能进一步区分供体选择、目标真实变化和其他模型因素；不能从“修改后尚有误差”直接得出其必然属于生物学变化。

## 7. 验证边界与结果报告规范

### 7.1 开发验证与未见测试

原始运行保持了生成阶段不读取真实 0.09 的条件。当前研究方向已根据 0.09 的误差形成；如果继续用该切片选择模块、带宽、配额规则或收缩参数，应将其明确视为开发验证切片。

最终泛化评价需要使用未参与选型的留出数据。推理代码不读取目标文件，与研究过程中没有根据目标表现选择方法，是不同的验证条件。允许利用训练切片或开发验证结果选择方案，但应如实区分其与最终测试。

### 7.2 两个研究方向的指标

| 目标 | 指标及报告方式 |
| --- | --- |
| 类型缺失 | 全部类型及预先定义稀有类型的覆盖率，列出缺失与额外生成类型 |
| 丰度不足/过量 | 各类比例差、绝对相对丰度误差、宏平均及稀有类单列 |
| 表达偏低 | 每细胞总表达均值相对偏差、逐基因均值 MAE/RMSE与简单基线差值 |
| 方差收缩 | 总表达及逐基因生成/真实方差比，标准差与方差降幅分别报告 |
| 联合结构偏离 | 非对角协方差误差、相关矩阵上三角 MAE；Pearson 为辅助 |
| 整体分布差异 | 总表达分布、分位数和 Wasserstein 距离 |
| 生成身份与空间合理性 | 类型内表达、标记特征及空间分布；不能只靠补齐标签宣称恢复 |

丰度不足率可定义为 `max(0,1-p_syn(c)/p_real(c))`，真实比例大于零时有效；同时报告双向相对误差，避免用过量生成换取覆盖率。对完全缺失的类型，表达相关性应记为不可计算，不通过仅平均已生成类型隐藏缺失。

表达与联合结构指标同时报告全局和按类型结果，避免类型比例改善造成全局协方差变化后，被误认为表达生成机制单独改善。基因集合、处理尺度、方差估计口径保持一致；常量基因相关性不可计算，应按预定规则单列，不能选择性删除表现差的输出。

类型内只有几枚细胞时，高维协方差和相关性只作描述性结果，报告支持数量及不确定性。重采样不确定性与不同生成随机种子带来的变化分别记录；改变基因/特征筛选、注释器或评价阈值同样属于需要固定的开发选择。

### 7.3 结论应对应其证据对象

- “保留供体加权分布中的依赖”需要条件推导或固定供体的对照。
- “减少稀有类型候选限制”需要候选数量、ESS及表达比较。
- “满足输入配额”需要验证赋型后的整数计数。
- “恢复真实中间切片”需要未见目标上的类型身份、表达和空间证据。
- “预测不确定性具有统计覆盖”需要独立样本上的覆盖与校准检验。

两张端点切片通常不足以唯一约束中间联合分布，但这是需要明确输入、假设和允许解空间的识别性问题。一个算法在中间切片存在剩余误差，不是不可识别性的证明，更不能自动排除优化、模型或测量因素。

### 8.2 支持概念定义的公开资料

1. [scDesign2：均值、方差及基因相关结构的生成评价](https://link.springer.com/article/10.1186/s13059-021-02367-2)。支持将边际统计和基因依赖分别评价，不提供本文改进模块的效果保证。
2. [POT 的离散运输实现](https://pythonot.github.io/_modules/ot/lp.html)。用于明确离散配额指派与求解器的概念；正式集成需核对本项目 POT 0.9.3 的接口和求解状态。
3. [SciPy 1.12 Poisson 定义](https://docs.scipy.org/doc/scipy-1.12.0/reference/generated/scipy.stats.poisson.html)。支持给定参数下的概率和分位数计算，不验证本文丰度先验或区间校准。
4. [CMU James–Stein 与 SURE 教学资料](https://stat.cmu.edu/~larry/=sml/stein.pdf)。用于区分经典收缩风险结论与本文尚待验证的谱系平滑规则。
